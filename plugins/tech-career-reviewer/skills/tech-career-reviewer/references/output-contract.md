# Output contract

Adapt the depth to the requested mode. A full review uses every applicable section below; a quick audit uses sections 1, 4, and 5.

## 1. Recruiter snapshot

Return five concise fields:

- Apparent target role and level
- Strongest signal
- Main doubt
- Thirty-second verdict
- Likely next action: progress, hold, or reject based only on supplied material

State that this is a material review, not a prediction of an employer's decision.

## 2. Review context

List the target, supplied sources, missing sources, assumptions, and important limitations. Do not reproduce unnecessary personal data.

## 3. Evidence map

Use a compact table:

| ID | Claim or evidence | Source | Status | Relevance |
|---|---|---|---|---|

Include material claims only. Use `Supported`, `Candidate-confirmed`, `Inferred — confirm`, `Unsupported`, or `Contradictory` exactly.

## 4. Scorecard

Use the common 0–4 scale:

| Dimension | Score | Evidence | Why it matters |
|---|---:|---|---|

Use `Not enough evidence` instead of a number when required. Explain that scores assess the current material, not the candidate's worth or hiring probability.

## 5. Prioritized findings

Order by Critical, High, Medium, then Low. For every finding include:

- observation;
- evidence IDs;
- gap type;
- recruiter impact;
- concrete action.

Keep the list focused. Do not bury high-value changes under cosmetic advice.

## 6. Missing-evidence questions

Ask at most seven questions. Explain which claim or section each answer could improve.

## 7. Suggested rewrites

Use this structure for each substantive rewrite:

**Original:** existing text

**Proposed:** revised text

**Evidence:** E1, E4

**Status:** supported, candidate-confirmed, or confirm before use

**Why:** concise rationale

Do not present placeholder-bearing copy as final.

## 8. Channel-specific actions

Separate recommendations for:

- CV or resume;
- LinkedIn;
- GitHub or portfolio;
- target-job tailoring.

Omit unavailable channels rather than inventing observations.

## 9. Proof plan

Recommend up to three artifacts with the highest expected value. State the gap each artifact addresses and a realistic completion scope.

## 10. Readiness verdict

Choose one:

- **Ready:** positioning and evidence support applications now; refinements are optional.
- **Ready after focused edits:** evidence exists, but presentation materially weakens it.
- **Needs evidence recovery:** likely relevant experience is not sufficiently documented.
- **Target requires a bridge plan:** a material qualification gap remains.

End with the next three actions in order.
